# Mister Bean Platform

בסיס הפלטפורמה המאוחדת של Mister Bean. הגרסה הנוכחית כוללת את מודול
השירות וניהול הלקוחות, ונבנתה כך שבהמשך ניתן יהיה לצרף אליה את מודולי
הלידים והצעות המחיר הקיימים.

## מה כלול

- פורטל לקוח ומנהל לקוח מרובה סניפים
- סביבת עבודה לנציג שירות ולמנהל מערכת
- לקוחות, סניפים ומכונות
- פתיחה וניהול של קריאות שירות
- הזמנות קפה חודשיות ואישור חריגות
- משימות, חוזים ודוחות תפעוליים
- ממשק מלא בעברית ובכיוון RTL
- כניסה מאובטחת באמצעות Firebase Authentication
- הרשאות לפי תפקיד ושיוך לחשבונות לקוח
- סנכרון נתונים בזמן אמת באמצעות Cloud Firestore
- מסך ניהול משתמשים והרשאות למנהל
- התראת אימייל למנהל על כל בקשת גישה חדשה
- מצב תצוגה לקריאה בלבד המדמה כל תפקיד ולקוח

## הפעלה

```bash
npm install
npm run dev
```

לאחר מכן פותחים את `http://localhost:3000`.

## מבנה הפלטפורמה

שכבת הנתונים מחוברת לפרויקט Firebase הייעודי. הישות המרכזית היא
`CustomerAccount`, והיא מיועדת
לשמש את הלידים, הצעות המחיר והשירות באמצעות `accountId` משותף.

פרויקטי הלידים והצעות המחיר הקיימים עדיין אינם משתנים:

- `boazaidel-png/mister-bean-`
- `boazaidel-png/mister-bean-quotes`
